## Selected work

| Project | What it is |
| :-- | :-- |
| **[Marocos-AI](https://github.com/Marocosz/Marocos-AI)** | The portfolio behind [marocos.dev](https://marocos.dev). A windowed desktop that runs in the browser, and an agent that answers about me from my own knowledge base rather than a canned prompt.<br /><sub>React 19, Vite, FastAPI, LangGraph, ChromaDB</sub> |
| **[Bussola-v2](https://github.com/Marocosz/Bussola-v2)** | Open-source personal SaaS: finances, bio-tracking, productivity and agenda in one BI dashboard, with agents doing the analysis.<br /><sub>FastAPI, React 19, LangGraph</sub> |
| **[TCC](https://github.com/Marocosz/TCC)** | Black-box audit of Spotify's recommender with four synthetic personas, asking whether automated curation widens musical taste or narrows it. My Information Management thesis.<br /><sub>Python, clustering, inferential statistics</sub> |
| **[Supporte-Agents](https://github.com/Marocosz/Supporte-Agents)** | The AI agent hub I built for the innovation team at Supporte Logística.<br /><sub>Python, LangChain, RAG</sub> |
